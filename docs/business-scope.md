# 业务需求梳理（产品待办清单）

本文件用于与产品/协作者对齐「多人协作记账 + Gitee 同步」相关范围，实施时按优先级拆任务即可。

## 账本与身份

- 单账本内角色：仅协作者、还是需要「只读/可写」等权限模型。
- 创建/删除/重命名账本的流程与文案（与 Gitee 仓库生命周期的对应关系）。

## 协作与冲突

- 多人同时编辑同一笔交易时的策略：以最后写入为准、还是需要显式冲突提示与合并 UI。
- 协作者仅通过 Gitee 邀请是否足够，是否需要在应用内展示协作者列表或操作记录。

## 数据与合规

- 导出格式与频率（例如完整 JSON 导出、仅交易 CSV）。
- 备份提醒策略（仅提示、或强引导定期导出）。
- 敏感字段（如备注、位置）是否在导出中脱敏。

## 体验与端上预期

- 与 iOS 主屏幕 PWA 体验相关的非功能需求：大字号、无障碍、关键操作确认等（与布局类需求区分）。

## 已落实的技术前提（供对照）

- 远端仅 Gitee；同步依赖用户打开应用后触发，弱网/失败时以本地 IndexedDB 为准并提示后续同步。
